# Prompted skills

Practical AI skills, examples and resources from [Prompted](https://www.youtube.com/@Prompted-VI), a Serbian-language channel about building applications, working with agents and automating everyday tasks.

From an idea to a result you can inspect and try yourself.

## Skill library

The library is being prepared. No installable skills have been published yet. Skills will be added alongside the channel experiments, with clear instructions, examples, requirements and known limitations.

## Repository structure

Each published skill will have its own folder under `skills/`, including a `SKILL.md` entry point and any necessary examples or supporting files. Installation instructions will be included with each skill.
